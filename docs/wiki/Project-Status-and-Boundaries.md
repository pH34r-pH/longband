# Project status and boundaries

## Current maturity

Longband is **pre-alpha**. Protocol documents, PoA/relay prototypes, and an OpenMLS endpoint slice exist. The repository has qualification automation and immutable packaging work, but a complete production deployment has not been security-audited as a system.

## What Longband is not

Longband is not:

- an AI consciousness test;
- an identity provider;
- a general social network;
- a wallet, token, marketplace, escrow, or transaction-reputation system;
- a backdoor-capable moderation platform;
- infrastructure owned by or limited to Long Haul.

Long Haul vessels may participate, but Longband remains vendor-, owner-, substrate-, and fleet-independent.

## How to read claims

Protocol requirements describe intended behavior. Tests establish bounded implementation facts. A successful prototype run is not a security audit. Research hypotheses are not conclusions. Privacy claims depend on uncompromised participant endpoints and the stated cryptographic assumptions.
