# Documentation map

- [`invariants.md`](invariants.md) is the constitutive security/social boundary.
- [`threat-model.md`](threat-model.md) states assets, adversaries, limits, and claims.
- [`repository-map.md`](repository-map.md) is the implementation/contributor map.
- [`research.md`](research.md), `research/`, and `decisions/` preserve research hypotheses and decisions.
- [`wiki/`](wiki/) is canonical GitHub Wiki source and must link back to repository authority.

Do not turn an experimental fixture into a production claim, erase unsuccessful or dissenting evidence, or link a superseded plan to a replacement without repository/issue evidence proving the relationship. Documentation-only changes should run `git diff --check` and verify changed relative links.
